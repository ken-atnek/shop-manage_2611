## 確定している前提（2026-10-19）

- 対象はClientの商品一覧。商品の確認・検索・絞り込みと、商品詳細への編集導線を設ける

- 入稿の有無は一覧に出さず、商品詳細で設定・確認する
- 対応対象は既存方針と同じPC・タブレット。スマートフォン対応は今回の対象に含めない
- 受注一覧から共通化した`common.scss`・`common.js`と、既存のボタンmixinを再利用する

## 画面構成と共通部品（確定）

ヘッダー・サイドバーは既存のClient共通レイアウトを使う。メイン領域はページ見出し → 検索・詳細検索 → 一覧見出し → 商品テーブル（または空状態）→ ページ送りの順とする。

ページ見出しは「商品一覧」だけとし、受注一覧のような日付は出さない（Kenの決定、2026-10-19）。

スクロールは縦横ともページ全体で行い、商品テーブルの中にはスクロールを出さない（Kenの決定、2026-10-19）。`.products-scroll`は通常のラッパーとして残し、スクロール用の`role`・`aria-label`・`tabindex`は付けない。表が画面より広い場合はレイアウト全体を広げ、ヘッダーの面・下線とサイドバーの面をページの右端・下端までつなぐ。

`table`には、一覧見出しの`h2`のidを`aria-labelledby`で参照して名前を付ける。

| 領域 | 使用する共通部品 | 商品一覧での内容 |
|---|---|---|
| ページ見出し | `.page-heading` | 主見出し「商品一覧」だけ。日付は出さない |
| キーワード・詳細検索 | `.search-box`・`.filter-bar`・`.detail-toggle`・`.search-panel` | 商品名・IDの検索と詳細条件 |
| フォーム | `.form-field`・`.form-check`・`.check-group`・`.date-range` | 公開状態・在庫の状態・更新日の期間 |
| 一覧見出し | `.list-heading` | 商品一覧の対象件数を表示 |
| 空状態 | `.list-empty`・`.show-all` | データなし、検索結果0件、全件表示への導線 |
| ページ送り | `.pagination` | 受注一覧と同じ表示ルール・見た目 |
| ボタン | `button-base`・`button-primary`・`button-secondary` | 検索は主、条件クリアは副。詳細検索は既存の切り替えボタン |

詳細検索の内部構造は既存の`.search-panel-inner`・`.search-fields`・`.search-actions`も再利用する。受注一覧固有のKPIや検索項目の全幅指定は、そのまま商品一覧の仕様として持ち込まない。商品一覧のフォーム配置は制作時に確認する。

### 詳細検索の共通動作

- キーワード欄に「検索」、その隣に「詳細検索」を置く。パネル内の操作は「条件をクリア」「この条件で検索」
- 開閉・パネル内クリアには`common.js`を使用する。`.detail-toggle`の`aria-controls`でパネルのidを参照し、`aria-expanded`とパネルの`inert`を同期する
- 通常の初期表示ではパネルを閉じ、開閉時のフォーカスは詳細検索ボタンに残す。入力エラー時は対象欄が見えるようパネルを開く
- 「条件をクリア」はパネル内の入力値を空にし、チェックを解除する。キーワードは維持し、パネル内の最初の`input`へフォーカスする。クリアだけで検索実行・全件表示への切り替えは行わない
- 受注一覧では最初の入力が注文日の開始日だが、商品一覧では実際のDOM順に従う。更新日の開始日へ固定するために共通JSを変更しない
- チェックボックス群と更新日の期間は`fieldset`・`legend`でまとめ、各入力に対応する`label`を付ける。キーワードもプレースホルダーだけをラベルの代用にしない

検索の一致方法・組み合わせなど、画面項目の決定だけでは確定できない細則は末尾の未確定事項へ分ける。

## 並び順・ページ送り（確定）

- 更新が新しい順で固定し、並び替えの操作は置かない
- 1ページ50件。`.pagination`を使い、受注一覧と同じ部品・表示ルールとする
- ページ番号と省略記号は最大7項目。全7ページ以下は全番号を表示。8ページ以上は最初・最後・現在ページの前後1ページを基本とし、空く範囲を「…」で示す
- 先頭付近は`1 2 3 4 5 … 最終`、途中は`1 … 前 現在 次 … 最終`、末尾付近は`1 … 最終-4 最終-3 最終-2 最終-1 最終`
- 「前へ」は2ページ目以降、「次へ」は最終ページより前だけ表示する。現在ページは`aria-current="page"`で示す。省略記号とページ位置表示は操作対象にしない
- 配置・現在ページ・ホバー・フォーカス・前後のアイコンは共通部品のままとする。ページ数・現在ページ・URLと検索条件の引き継ぎはバックエンドで組み込む

### 画面全体の状態

| 状態 | 表示・操作 | 制作確認用URL |

データなし・検索結果0件は受注一覧と同じ`.list-empty`を使用し、テーブルとページ送りを案内箱に置き換える。「すべての商品を表示」には`.show-all`を使う。

### 更新日の入力エラー

- 共通の`$color-error`（`#D21F3C`）による入力枠と`.form-error`のエラー文を使う
- 開始日・終了日の両方に`aria-invalid="true"`を付け、`aria-describedby`でfieldset内の1つのエラー文を参照する。正常時はエラー用属性・文を出さない
- エラー文は受注一覧と同じ「終了日は開始日以降の日付を指定してください」。日付の判定・検索処理はバックエンド担当者と合わせる

### 一覧内の表示状態

| 状態 | 確定している表示 |

| 画像なし | 画像の位置に代わりの表示を置き、画像がないことが文字でも伝わるようにする。具体的な見た目は未確定 |

公開状態と在庫の状態は別の情報として表示する。画像なしや非公開でも、商品名・価格・在庫数・編集導線の読み取りや操作を妨げない。

## 実装メモ（2026-10-19・公開バッジと2行表示のKen決定を反映）

### classと共通部品

- 共通のページ見出し・検索・フォーム・一覧見出し・空状態・ページ送りを再利用。初回制作では受注一覧・共通部分を変更せず、ルートの`scss/_colors.scss`には公開バッジの専用色2つとコメントヘッダーだけを追加。その後のページ全体スクロールへの変更は下記を参照
- 検索の配置：`.publish-field`・`.stock-field`・`.updated-field`。公開状態・在庫の状態を2列、更新日を全幅にした。KPIがないため検索の上余白だけを0にして、ページ見出しの下余白を使う
- 一覧：`.products-scroll`・`.products-table`。列は`.product-id`・`.product-image`・`.product-name`・`.product-price`・`.product-stock`・`.product-publish`・`.product-updated`・`.product-edit`
- 状態・操作：`.no-image`・`.stock-note`・`.publish-state`・`.is-private`・`.edit-link`
- tableの名前は`aria-labelledby="product-list-heading"`でh2を参照。詳細検索は`product-search-panel`、日付エラーは`product-date-error`を参照する

### 決定済みの見た目と調整中の寸法

- 表の最小幅は`86rem（860px）`へ縮小（旧960px）。在庫列は`9rem`、更新日時列は`11rem`、バッジを収める公開状態列は`10rem`。商品名だけを残り幅（最小幅時264px）にし、固定レイアウトで長文を行数制限なしに折り返す。セル余白は`1.2rem`のまま。列幅・最小幅は今回の実測による調整値
- 公開状態は角の丸い塗りのバッジ。公開は`$color-publish-public（#3A5F95）`、非公開は`$color-publish-private（#6B7079）`に`opacity: 0.7`。白文字・`fz(14)`・500（太字ではない）、幅`5em`・中央ぞろえ、高さ`2.8rem`、左右余白`1.2rem`、角丸`100vmax`、枠なし。非公開の実表示約2.8:1は、控えめに見せるためのKenの決定として白文字4.5:1の例外（2026-10-19）。ホバー色は変えずカーソルは`default`。非公開の行全体は薄くしない
- 在庫ラベルは数字の下に`display: block`で置き、`fz(12)`の補助色文字・右揃えを維持。左余白をなくし、全行の数字の右端をそろえた。「3・残りわずか」は表示例で、基準値を確定したものではない
- 更新日時は1つの`time`の中を日付・時刻の2つの`span`に分け、block表示・右揃え・`tabular-nums`。文字サイズは変えず、子も`font-size: inherit`。`datetime`は元の値を維持
- 画像なしは48px角のグレーの面＋「画像なし」。`image-off`案は採用していない
- 行ホバーは`$color-bg-detail`。編集リンクは40px角・丸い領域で、補助色→本文色＋白背景のホバー。通常は1pxの透明枠、ホバーでは`$color-border-card`の1px枠を表示し、文字色・背景色・枠色に`$transition-base`のtransitionを付ける
- ページ固有の指定はすべて`products.scss`内。`fz()`を入れ子で重ねず、table内部の構造要素・time等は`font-size: inherit`。入力欄の16px固定は共通スタイルを使用
