# Master 受注一覧 — 画面資料

## 位置づけ

2026-10-24のKenの決定を基に、Master受注一覧のClientとの違いをまとめる。KPI・検索・注文カード・発送状況・展開行（備考・入稿画像・キャンセル／返品の記録）・ページ送り・状態は[Client受注一覧の画面資料](CLIENT_ORDER_LIST.md)と[Client受注一覧の申し送り](../coding/HANDOFF_CLIENT_ORDER_LIST.md)に従い、本資料には違いだけを書く。業務仕様の正は[SPECの「Masterへの展開方針」](../SPEC.md#masterへの展開方針)とする。

- 制作状況：制作前（2026-10-24）
- 作る順番：Masterの最初の画面（受注 → 商品 → 店舗 → 顧客 → 集計）

## 確定事項（2026-10-24、Kenの決定）

- 全パートナーの注文を並べる。直接ログインしたときの行き先はこの画面
- 操作はClientの受注一覧と同じ（発送状況の変更、キャンセル・返品の記録）
- パートナーの絞り込み：KPIの近くに「パートナー」のセレクトを常に出す。初期は「すべてのパートナー」で、選ぶとすぐ反映する（[集計の店舗セレクト](CLIENT_SALES.md)と同じ形）。KPIの件数も選んだパートナーに合わせる。この形を、商品・店舗・顧客の一覧でも下敷きにする
- 店舗での絞り込みは置かない（Clientの受注一覧とそろえる）
- 注文カード：注文番号の行に「パートナー名／店舗名」を1行で出す。この位置は、のちにClientの受注一覧で店舗名を出すときにも使う
- ヘッダー：「サイトを確認」は置かない
- サイドバー：受注一覧・商品一覧・店舗・顧客一覧・集計の5項目を最初から並べ、まだ作っていない画面のリンクは`#`にする。idと開閉の保存の名前はMaster用（`master-navigation`・`kumanichi-master-sidebar`）
- 制作用PHPは`shop-master/`に別に作る（Clientの`shop-partner/orders.php`をもとにコピーし、Masterの違いを足す）。ヘッダー・サイドバーは`shop-master/includes/`、JSはMaster用の`common.js`を`shop-master/assets/js/`に置く。Clientのファイルは変えない
- 色はMasterの仮の値のまま（[DESIGN_TOKENS.md](../../DESIGN_TOKENS.md)）。Master＝青の割り当ては熊日に確認中のため、ここでは決めない

## 制作の前提（ログイン系・Clientの書き方にそろえる）

- ヘッダーの表記は「熊日モール」＋管理画面名「管理画面」とし、ログインの上部表記「熊日モール｜管理画面」とそろえる。`title`は「受注一覧｜熊日モール 管理画面」
- 確認する幅は、Clientの受注一覧と同じ1280×800・1024×768・834×1194
