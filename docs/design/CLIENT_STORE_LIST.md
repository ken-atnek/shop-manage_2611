# Client 店舗一覧 — 構成・項目の検討

## 位置づけ

2026-10-20のKenの決定を基に、Clientの店舗一覧を整理する画面資料。状態は「仕様確定（制作前）」で、画面実装は未着手。今回決まった内容と、引き続き残る案・未確定事項を分けて記載する。

「確定」はKenの決定、「案」はKenが画面で調整・決定する内容、「未確定」は業務条件や今後の確認事項とする。見た目や入力条件を推測で確定しない。

店舗と送料の業務仕様は[SPECの店舗と送料の確定事項](../SPEC.md#店舗と送料の確定事項)を正とし、本資料には再掲しない。フォームは[店舗の登録・編集](CLIENT_STORE_FORM.md)、共通一覧は[商品一覧](CLIENT_PRODUCT_LIST.md)、見た目は[デザイントークン](../../DESIGN_TOKENS.md)・[デザイン方針](DESIGN.md)、共通構造は[共通レイアウト](../coding/LAYOUT_TEMPLATE.md)・[Client共通申し送り](../coding/HANDOFF_CLIENT_COMMON.md)を参照する。

## 確定している前提（2026-10-20）

- 対象はClient。呼び方は「店舗」とするが、今後変更する可能性はある
- 画面は一覧と、登録・編集を共用する1フォームの2つ
- サイドバーは「店舗」1項目だけとし、一覧へ入る
- 一覧に「店舗を追加」ボタンを置き、新規フォームへ進む。商品一覧の登録導線とは異なる
- 一覧のデータは[SPECの一覧の並び順・集計・更新日時](../SPEC.md#一覧の並び順集計更新日時)に従う。並び順・商品数の集計条件・更新日時の契機は画面側で別に定義しない
- 送料方式の表示は「サイズ別」／「サイズ共通」とする
- 送料は店舗の登録・編集フォームで設定する
- 商品フォームの表示文言は「店舗」へ変更済み（2026-10-20）。サイドバーの表示文言は今回の対象外で、次回変更する。コードの名前は変更しない

## 画面構成

| 領域 | 内容 | 区分 |
|---|---|---|
| 共通ヘッダー・サイドバー | Clientの共通部品を利用し、現在地を「店舗」にする | サイドバー項目は確定。配置は既存仕様を参照 |
| ページ見出し | 「店舗一覧」の見出しの右に「店舗を追加」。834px幅では見出しの下に回す | 追加導線・位置は確定。見出し「店舗一覧」は案 |
| 一覧 | 店舗名・運送会社・送料の方式・商品数・更新日時・編集の6列 | 案 |
| 検索・詳細検索 | 店舗数が少ないため置かない | 案 |
| 一覧の操作 | 並び替え・ページ送りは置かない | 確定。データの順序はSPECを参照 |

KPIや一覧内の即時編集は、この案には含めない。

## 項目

### 一覧の列（構成案と確定した表示）

| 列 | 内容・表示案 | 確認が必要な点 |
|---|---|---|
| 店舗名 | 登録した店舗名をテキスト表示。長い名前は折り返す | 購入画面にも表示するかは未確定 |
| 運送会社 | 選択済みの会社名を表示 | 初期対象・規格は[SPEC](../SPEC.md#運送会社の規格正の資料)を参照 |
| 送料の方式 | 「サイズ別」／「サイズ共通」の文字で表示（確定） | 都道府県欄への入力補助「全国一律」と区別する |
| 商品数 | 集計済みの商品数を右揃えで表示する案 | 集計対象は[SPEC](../SPEC.md#一覧の並び順集計更新日時)で確定 |
| 更新日時 | 日付・時刻を表示。商品一覧と同じ2行表示を候補にする | 更新の契機は[SPEC](../SPEC.md#一覧の並び順集計更新日時)で確定 |
| 編集 | 商品一覧と同じ編集アイコンから編集フォームへ遷移 | 読み上げ名・titleには対象の店舗名を含める案 |

送料の方式と、都道府県欄への一括入力補助「全国一律」は別の概念。[SPEC](../SPEC.md#店舗と送料の確定事項)の送料方式を増やすものではない。

## 操作と状態

| 操作・状態 | 表示・動作 | 区分 |
|---|---|---|
| 店舗を追加 | 登録・編集共用フォームの新規状態へ進む | 確定。URLは未確定 |
| 編集 | 対象の店舗の保存値を表示する編集状態へ進む | 案。共用フォームは確定 |
| 通常 | SPECで決めた順序のまま店舗を一覧表示する | 順序は確定。表示の細部は案 |
| 店舗未登録 | 「店舗がまだ登録されていません」等の案内を出し、「店舗を追加」への導線を保つ | 案 |
| 取得失敗 | 共通の一覧エラー表示を利用し、再読み込みの導線を検討する | 案 |
| 並び替え・ページ送り | 操作・ページ番号・次へ／前へは表示しない | 確定 |
| 削除・停止 | 最初は操作を置かない | 案。停止時等の商品の扱いは未確定 |

検索を置かない案のため、検索結果0件や詳細検索の開閉状態は制作候補に含めない。リンクは`a`、操作ボタンは`button`を使い、一覧全行をクリック対象にするかなどを先に固定しない。

## 見た目の案（Kenが画面で調整・決定）

| 対象 | 案・確認内容 |
|---|---|
| 共通部分 | 商品一覧のヘッダー・サイドバー・見出し・罫線・表の文字を基準にする |
| 追加ボタン | 見出しの右、834px幅では見出しの下が確定。間隔やボタン幅を画面で調整する |
| 一覧 | 店舗名を広く取り、商品数・編集は必要な幅に収める。ページ全体で縦スクロールする |
| PC／タブレット | 店舗名・会社名・日時の折り返しを確認。幅不足時の横スクロールや列幅は実画面で判断する |
| 状態 | 方式は文字で伝える。公開／非公開のバッジを店舗の状態として流用しない |
| 空・エラー | 共通の一覧状態部品を参照し、追加導線と案内の関係を確認する |

新しい色・余白・寸法のトークンはこの資料では確定しない。

## 未確定事項・次に決めること

- 6列の構成案・検索なしの案、正式な列名・一覧の見出し・空状態の文言。送料方式の表示は確定済み
- 列幅、長い店舗名、日時の表示、追加ボタン周辺の余白。ボタンの配置は確定済み
- 834px幅で見出しの下へ回す配置を満たす具体的なブレークポイント
- お客様の画面（購入画面）への店舗名表示は、[SPECのバックエンドへの確認事項No.3](../SPEC.md#バックエンドへの確認事項)の回答後に決める。表示する場合、店舗名はお客様向けの名前になる
- 削除・停止時の商品の扱い、Masterでの扱いなどは[SPECの未確定事項](../SPEC.md#店舗と送料の未確定事項)を参照
