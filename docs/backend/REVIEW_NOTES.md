## 先に決めたい順序（案）

1. 購入側システム、販売店別注文・決済・送料の責任境界。
2. 保存可否に直結する梱包・クール便・通常送料未設定時の扱い。
3. 商品画像の運用上限、食品オフ時の未保存値、アレルゲンの検証条件。
4. 認証・権限・環境構成を確定し、Blade移植の対象画面を決める。
