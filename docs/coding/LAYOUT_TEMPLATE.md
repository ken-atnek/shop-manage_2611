# 共通レイアウトテンプレート

## 位置づけ

ECサイト管理画面の共通構造を整理するためのテンプレート。

画面構成が確定するまでは、特定のレイアウトを強制しない。`docs/SPEC.md`と実装済みの共通構造を優先する。Figmaは必要な場合のみ参照する。

## 管理画面の基本構造

```text
管理画面
├── ヘッダー
│   ├── サービス名・ロゴ
│   ├── 補助ナビゲーション
│   └── アカウントメニュー
├── サイドバー
│   └── メインナビゲーション
└── メイン
    ├── パンくず（必要な場合）
    ├── ページヘッダー
    │   ├── ページタイトル・説明
    │   └── 主要操作
    ├── フィルター・検索（必要な場合）
    ├── コンテンツ
    └── ページ下部操作（必要な場合）
```

## HTML構造の参考

HTMLはユーザーが実装するため、以下は構造を検討するための参考とする。

```html
<body class="admin-page">
  <header class="admin-header">
    <!-- サービス名 / アカウントメニュー -->
  </header>

  <div class="admin-layout">
    <aside class="admin-sidebar">
      <nav aria-label="管理メニュー">
        <!-- メインナビゲーション -->
      </nav>
    </aside>

    <main class="admin-main">
      <header class="page-header">
        <div>
          <h1>ページタイトル</h1>
          <p>ページの説明</p>
        </div>
        <div class="page-actions">
          <!-- 主要操作 -->
        </div>
      </header>

      <section class="page-content">
        <!-- ページ固有の内容 -->
      </section>
    </main>
  </div>
</body>
```

## 画面ごとに確認する項目

- ページタイトルと説明
- 主要操作の位置と優先順位
- 検索、絞り込み、並び替え
- 一覧・詳細・編集の関係
- 保存、キャンセル、削除の配置
- 空状態、読み込み中、エラー状態
- モーダル、ドロワー、確認ダイアログ
- 狭い画面でのサイドバーとテーブルの扱い

## 注意

- 共通領域の構造とスタイルを揃え、共通Sassを再利用する
- ブラウザで画面幅を変え、レイアウトの挙動を確認する
- 固定配置は必要な箇所だけに限定する
- 画面固有の仕様は`docs/SPEC.md`へ記載する
- デザイントークンは`DESIGN_TOKENS.md`を参照する
- class名は実装開始時に既存コードへ合わせて調整してよい
